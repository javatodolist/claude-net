我一直都有体验ChatGPT，并不是它的写作变差了，而是它对提示词的要求更高了，因为现在是智能路由，你无法知道调用的是哪个模型，所以如果你的提示词太简单，它就会调用差的模型，还有就是模型的性能有关。
当免费的GPT-5的额度使用完后，它就会主动切换成GPT-mini，能力也不行，能力等级你可以参考一下这张图。
再说到为什么ChatGPT要强卷价格战这个话题，从GPT-5就不难看出，模型能力的提高远没有一年前那么巨大了，所以随着时间的增长，模型的能力会越来越接近。
其中很大原因就是，数据蒸馏，算力的投入，前者，大家用好的模型生成的数据训练，效果自然是越来越好，后者，先美国顶尖的那几家厂家Grok、Claude这些在算力上的投入不比OpenAI少，OpenAI的危机感还是得要有的。
另外一方面，纯个人瞎猜，就是OpenAI什么市场都不想放过，大小通吃，从它投资机器人、智能眼镜、做编程工具这点就可以琢磨点味道出来。
