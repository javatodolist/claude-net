很简单，我之前总结了五种订阅ChatGPT的方法，感兴趣的可以试一下。
分别是通过Google绑定国内的信用卡、礼品卡、第三方充值平台、以及搞不定麻烦的镜像站，还有程序员非常喜欢用的API中转站。

这里给大家简单说下。
目前最好的方法就是自己有一张全币卡，然后绑定google play，通过内购的方式购买。
最安全，也是最便宜的。
其次是礼品卡，不过礼品卡稍微有一点麻烦，首先你要有一个苹果设备，第二还要去申请美区ID，最后购买礼品卡。
同时礼品卡的也有一点缺点，那就是你大概率买的是黑卡，所以你的apple ID有可能被封，从而导致你的GPT账号登录不了。
第三种方法，最便捷的方法，第三方机构——WildAI
为什么说它比较好，因为它是信用卡充值的，其他的产品基本上是礼品卡充值，多多少少有一些风险。
还有一种方法，可能仅适合程序员，那就是API调用，好处就是用多少扣多少钱，坏处就是交互不行，体验感不行。
顺带说下，如果你走 API 这条路、而且用的是 Claude，国内用户可以试试 [Code80](https://code.ai80.vip/home)，它是真实订阅帐号转出来的 Claude API，跟官方完全兼容，换个 endpoint 就能用，还支持国内支付，省掉海外卡的麻烦。地址 [code.ai80.vip](https://code.ai80.vip/home)。
