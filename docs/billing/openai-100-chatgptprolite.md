# OpenAI 有望推出月费 100 美元的 ChatGPTProLite 订阅，此定价策略有何考量？

昨天看到一个挺有意思的事。
有个叫Tibor Blaho的老哥，从ChatGPT前端的JavaScript代码里扒出来一个新订阅，叫ChatGPT Pro Lite，月费100美元。
付款页面都有了，后端API里价格字段写的清清楚楚，100.0。
然后整个AI圈就开始讨论了。
先给不太了解的朋友解释一下，这个定价到底填了什么空。
ChatGPT现在的订阅有个很经典的问题，就是档位断层太严重。20美元的Plus，然后直接跳到200美元的Pro，中间空了一个巨大的真空地带。
这10倍的价差，一直被人吐槽。
你想要比Plus更强的能力，但又没到需要花200美元的地步，怎么办？没得选。
Pro Lite就是来堵这个洞的。
但是，如果你只把这件事理解成"填补定价空白"，那你可能只看到了三分之一。
代码里有一个字段，叫reasoning_limit_boost，这个东西很关键。
OpenAI内部有个隐藏参数叫"Juice"，控制模型的最大思考深度。
Plus用户的Juice值是64，Pro用户最大到128。数字越大，模型想得越深，回答质量越高。
Pro Lite大概率会给你一个介于两者之间的Juice值。
但这还不是最关键的部分。
就在Pro Lite被发现的同一周，Tibor还爆出了另一个料。
OpenAI正在洽谈收购开源Agent框架OpenClaw，Sam Altman亲自发文说，未来属于"多智能体协作"。
你把这两件事放在一起看，就有意思了。
一个后台持续运行的AI Agent，烧的算力可能是普通聊天的几十倍。
你不可能用20美元一个月的订阅来支撑这种消耗。
所以，100美元这个价格，与其说是"便宜版Pro"，不如说是Agent功能的最低入场门槛。
然后还有一件事，我觉得挺值得聊的。
就是，你有没有发现，ChatGPT这两年，正在越来越像Claude。。。
Projects功能，Claude先做的。让AI操控电脑的Computer Use，Anthropic 2024年10月就公测了，OpenAI很久之后才有Operator。MCP协议，Anthropic 2024年11月开源，Sam Altman到2025年3月才说"我们也要支持"。
现在轮到定价结构了。
Anthropic的Claude个人订阅是三档：免费、20美元Pro、然后Max分100美元和200美元两个版本。
OpenAI加上Pro Lite之后，个人订阅变成五档：免费、Go 8美元、Plus 20美元、Pro Lite 100美元、Pro 200美元。
Pro Lite对标的就是Claude Max 5x，这个几乎是明牌了。
说实话，这件事让我想到一个更有意思的问题。
100美元，到底是贵还是便宜？
这取决于你怎么看AI订阅这件事。
如果你把它理解成"买一个聊天工具"，那100美元很贵，毕竟大部分人用20美元的Plus已经够了。
但如果你把它理解成"雇一个随时待命的助手"，那100美元可能是你今年花得最值的钱。
AI订阅正在从"工具消费"变成"生产力投资"。
这个认知迁移，才是OpenAI这次定价背后真正想押注的东西。
至于你值不值得买嘛。。。
先问问自己，你现在用AI，一个月能不能创造超过100美元的价值。
能的话，买。不能的话，Plus挺好的。
就这么简单。
