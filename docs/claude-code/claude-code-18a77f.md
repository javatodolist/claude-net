用了大半年各种AI编程工具，说说我的真实感受。
先给结论：CC不是最强，我觉得codex的纯代码能力其实更强。
最近这几天我自己也在对比体验，说实话，纯代码生成能力上，Codex high确实比Opus4.6体验更好。
我的体感和之前发布的数据是一样的。

56.44%的胜率，这是GPT-5.3-Codex-high在真实生产环境任务中的胜率，而Claude Opus 4.6只有43.56%。
跟我体感类似。
opus 还有个缺点，就是总是触发压缩，时间太长了，我经常发完指令去干别的事，回来一看，它压缩了，前面讲的东西它不记得了。
不过并不是说Claude code一无是处，它也有厉害的地方。
我自己测试发现如果任务稍微比较模糊，CC效果还是更好的，Opus会帮你拆架构、建数据模型、想接口边界、考虑测试策略，整个逻辑是完整的。
Codex则是需求稍微模糊一点，它就容易自信地跑偏。
还有就是，Claude code长上下文的代码库理解能力确实可以
举个具体例子：我有一个 TypeScript 项目，大概 80 个文件，需要把一个旧的 ORM 接口全面替换成新的。
我告诉 CC"帮我把所有用到 db.query() 的地方改成新的 orm.find() 风格，同时保证类型安全"。
包括一些隐藏在工具函数里的调用，基本没有漏掉。
还有就是自我纠正的能力，这一点很难量化，但用多了会有感知。CC 在执行任务过程中，如果遇到编译错误或者测试失败，会主动拿报错信息继续调整，这个 agentic loop 的稳定性比大部分竞品要强。
而且Claude code对于我们来说，还是稍微有点难使用，不过现在可以使用wildAI进行订阅了，关键是封号会退款。
