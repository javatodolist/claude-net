# gpt越来越不行了，是为什么？

AI工具导航站
同名“AI工具导航站”，跟上时代的脚步
感觉就像当年的iPhone，出到十几代了，总有人说“乔布斯之后再无创新”、“苹果药丸”。那么，GPT真的“不行了”吗。
我觉得吧，这得分两头说。
如果你单指ChatGPT背后的那个“大模型本身”，比如最新发布的GPT4.5 或o4-mini，它确实是落后了，不如Gemini 2.5 Pro和Grok模型。
这背后大家觉得它越来越差可能有几个原因：
“安全对齐”的副作用：为了让模型更安全、更负责任、更符合普世价值观，OpenAI肯定做了大量的对齐工作。这种对齐，让回答变得更“正确”但也更“套路化”。
2. 模型能力的“天花板”错觉：随着我们对大模型的使用越来越深入，期望值也水涨船高。以前随便一个回答都觉得惊为天人，现在可能对标的是行业顶尖专家的水平。这种期望值的拉高，自然会显得模型“进步缓慢”甚至“退步”。
3. 用户的“审美疲劳”与“场景固化”：天天用，新鲜感自然会下降。而且很多人用GPT，可能还是停留在简单的问答、写周报、等场景，当这些场景被一些其他的应用“榨干”后，就容易觉得它“不过如此”。
4. 竞争对手的快速迭代：现在全球大模型遍地开花，国外的gemini、Grok、国内的Kimi、文心一言、通义千问等等，都在某些特定领域或者中文理解上表现优异，有了对比，自然会觉得GPT“没那么独一无二”了。
5. ChatGPT要的太多：它不再是那个纯粹追求底层模型的AI公司了，比如ChatGPT做AI视频、机器人、AI浏览器等等。
所以，单从“底层模型”在某些用户感知上的“绝对领先性”来说，确实不像一年前那样一枝独秀。这很正常，科技发展就是这样，你追我赶，这也算的上是好事。
但是！如果你说“ChatGPT”这个应用不行了，那我可得好好反驳一下了。这句话，绝对是没经过深度思考的！
为啥？因为今天的ChatGPT，已经远远不止是一个简单的问答机器人了，它是一个应用，一个APP。
1.GPT-4o的绘画功能：前段时间GPT-4o的绘画功能发布，单单一个AI绘画功能，就让多少设计师和爱好者直呼“牛逼”，给ChatGPT带来了多少新用户和日活？它把AI绘画的能力再一次拔高。
2. GPTs：现在各种Agent概念满天飞，但OpenAI通过GPT Store，让普通用户也能轻松创建和使用定制化的GPT应用，这个生态的价值是巨大的。我个人就非常喜欢用各种GPTs来处理特定任务，比如分析研报、写小红书文案.它依旧是我喜欢使用的ChatGPT功能，没有之一。
3. Sora：我承认Sora确实没有可灵好，但是奈何只需订阅ChatGPT会员，就可以免费使用，性价比来说，它会更高一点。
4. 高级语音功能：ChatGPT的语音功能，从最早的版本到现在的GPT-4o。我敢说，它依旧是我目前体验过的最接近真人对话的AI语音助手，没有之一。无论是闲聊、实时翻译还是作为驾驶时的语音伴侣，体验都非常出色。
个人认为最大的败笔就是对国内用户的苛刻，它不支持国内信用卡，连香港用户都不行，只能通过第三方平台或找朋友。
最后，要说“ChatGPT这个应用不行了”，那绝对是只见树木不见森林。它依然是AI领域的领头羊之一，凭借其强大的多模态能力和不断扩展的生态系统，在可预见的未来，依旧会是很多人（包括我）AI工具箱里的主要输出工具。
