-1-官网/API使用
最直接的方式是通过官网使用 Claude，或者调用官方 API 将其接入自己的第三方应用。

不过，Claude的封控政策比较严格，很多用户反馈前脚刚注册成功，后脚就被封控，如果你不想频繁被封，可以尝试以下替代方法。
-2-亚马逊云
亚马逊云的Bedrock大模型托管平台允许用户无缝接入多个AI大模型，并支持无服务器运行。
该平台集成了多个顶级的主流大模型，Claude 3.7 Sonnet 早已被接入。
-3-OpenRounter
OpenRouter 是一个聚合式大模型 API 平台，允许用户通过一个 API 访问多个不同公司的 AI 大语言模型。
开发者可以灵活选择不同 AI 模型进行推理，而无需单独注册和管理多个 API。
OpenRouter 官网的聊天窗口也接入了 Claude 3.7 Sonnet
-4-Poe
Poe相信大家并不陌生，与其他平台不同，Poe不仅集成了顶级的主流AI聊天模型，还接入了众多的AI图片，视频，音频模型。
只需注册一个账号，里面所有的模型都可以使用。
可直接在主界面这里就可以使用 Claude 3.7模型，免费用户每日3000积分，日常体验完全够用。

如果您是开发人员，想要使用Claude写代码，那Cursor绝对是不能错过，目前被认为是最棒的AI编程助手，在Claude 3.7发布后，Cursor也是第一时间就宣布接入，感兴趣的可以去体验一下。
