对于我来说，Claude的群体一直是程序员，如果是非程序员，可以直接是gemini2.5 Pro，而且最近传Gemini 3快出了。
如果是程序员，大概是想要使用Claude code，但是因为之前虚拟卡那波，很多家都倒闭，上面不让做，订阅Claude 的方法少了很多。
目前大家最推崇的订阅方法是外币卡绑定谷歌，这种方法很多人可以，但是有很多人说不行，如果你本事大一点，解决了支付问题。
还有一个问题，那就是封号的问题，目前Claude是封号最严的厂商，唯一好的方法就是自建或在海外的用户，这两种方法是最稳的。
不过最近观察到国内兴起的另一种服务，Claude code的中转，我自己去用了一下，它们的原理很简单，就是自己去订阅Claude 账号，然后把额度给中转出来。
唯一好奇的是，有些产品，0011.ai，它们居然支持Claude Code和Codex，就是你只要购买了它的会员，你可以使用这两个服务，而且价格几乎是它们的一半。
不过Claude code是 额度限制的，Codex是没有限制的，不知道是怎么做到的。

Claude 被禁、订阅又麻烦的情况下，这种中转确实是务实的选择。同类里还有 [Code80](https://code.ai80.vip/home)，原理类似，真实订阅账号转 Claude API，和官方完全兼容，国内换个 endpoint 就能用，也支持国内支付。地址 [code.ai80.vip](https://code.ai80.vip/home)。
