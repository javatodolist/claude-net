# 你更喜欢使用codex还是claude来进行编程呢？

等了这么久，GPT-5.4 Thinking 和 GPT-5.4 Pro 终于来了，最近关于Codex和Claude code编程能力谁更强的话题，一直在社区争论不休。
不过有一点可以确定的是，越来越多的博主都开始推荐大家使用Codex了，因为它比Claude code更具性价比！
所以今天这个文章就教大家如何部署 Codex，包括没有海外信用卡怎么订阅 ChatGPT Plus 会员，以及如果没有 GPT Plus 会员又该如何使用 Codex！一共三种方法。
方法一：订阅 ChatGPT Plus 会员
这是最直接的方法，直接去 ChatGPT 官网订阅 Plus 或者 Pro 会员，订阅之后就可以直接使用 Codex 了。
但问题来了国内用户没有海外信用卡怎么办？
这里教大家一个常用的方法：使用 WildAI这类第三方代充平台，它支持支付宝充值，不需要给账号和密码，就能直接升级ChatGPT Plus会员。
传送门：https://bewild.ai?code=AIG
我之前的文章有详细的介绍如何使用wildAI订阅ChatGPT Plus会员，感兴趣的可以看看。
不是礼品卡，不是虚拟卡，2025最新ChatGPT Plus订阅教程，小白都学得会！
Plus 会员每个月 20 美元，Pro 是 200 美元，如果你只是日常编程使用，Plus 基本够用。
下面是详细的部署教程。
苹果电脑安装 Codex 非常简单，打开终端，输入 brew install --cask codex，等待安装完成。
然后输入 codex 回车，它会提示你登录，选择第一个用 ChatGPT 账号登录，浏览器会自动跳出来让你授权，授权完成就可以直接用了。
整个过程不需要提前装 Node.js，比之前方便很多。
Plus 用户每 5 小时大约可以发送 30到150 条本地消息，Pro 用户是 300到1500 条。
登录成功后
接下来我们使用codex做一个网页小游戏，codex可以在本地直接对文件进行操作，Plus版本的Codex相应速度是非常快的，并且会自适应调用需要的技能，做出来的成品效果也是非常惊艳。
游戏的ui设计和界面布局非常美观，玩法和内容十分完善。
如果不满意你可以让他再次修改或者直接改变游戏的风格。
方法二：0011.ai 中转站
如果你不仅想要使用codex，还想要使用Claude code，那这个方法非常适合你—
0011.ai是采用积分制的，意味着订阅了它的会员，无论是Codex还是Claude code都可以直接使用。
传送门：https://0011.ai/i/AIG
价格也比官网便宜不少，如果只是想尝试一下性能，它这边还提供了按量付费套餐，用多少token扣多少钱，绝不浪费。
按照步骤进行购买，支付方式这里选择微信支付，然后输入自己的姓氏，扫码完成支付就可以了
购买后会获得一个 API Key，然后点击codex使用教程，在里面找到自己的电脑系统，根据教程来操作。
目前中转 Codex 的具体URL格式，每家平台不一样，建议直接找你买的那个平台的对接文档，照着填就行。
另外0011平台还支持两台设备同时在线，完全可以和朋友合租，两个人分摊费用，直接省一半的钱。
方法三：国产模型的编程工具
如果你既不想订阅 ChatGPT Plus，又觉得中转站麻烦，还有一个超省钱的选择——直接用 Kimi Code CLI。
它是 Moonshot AI 官方推出的编程终端工具，功能和 Codex 几乎一样，价格只有 Codex 的十分之一，而且完全支持国内网络，0 封号风险。
安装只需要一行命令：pip install kimi-cli，装完输入 kimi 就能用，非常适合预算有限的同学。
不过唯一的缺点就是没有codex好用，不止是kimi，minimax、阿里也出了，大家感兴趣的可以去体验一番
如果过程中遇到了问题或者是有其他更好的方法，欢迎在评论区讨论。
