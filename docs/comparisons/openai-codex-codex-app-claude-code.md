# 如何评价OpenAI发布Codex桌面版Codex App？和 Claude Code 相比怎么样？

面对谷歌、Anthropic狂轰乱炸！
OpenAI终于憋不住了 就在今天凌晨，OpenAI 紧急推出Codex 桌面版 ！
这可以说是奥特曼的希望所在，也是连忙说爱了爱了！
官方的给Codex 桌面版的定位非常清晰：“AI 编程的指挥中心”。
简单来说，以前我们是用 AI 写代码，现在是让 AI 帮我们打工（Agent）。
你不再是苦哈哈敲代码的码农，而是指挥不同Agent的“司令官”。
OpenAI 这波显然是急了，直接把压箱底的绝活都拿了出来。效果到底有多强？给大家拆解几个核心亮点就清楚了。
以前我们用 Cursor 或者是网页版 ChatGPT，只能是：你写一行，它补一行；或者你问一句，它答一句。
但 Codex 桌面版完全变了。它引入了一个叫“工作树”（Worktrees）的概念。
你可以在左侧开启多个线程，指派不同的 Agent 去干活。比如：
Agent A： 去帮我重构一下数据库接口；
Agent B： 给新功能写单元测试；
Agent C： 帮我修一下昨晚的 Bug。
并且这些 Agent 全部在后台的独立环境里运行，完全不会干扰你当前的工作。
OpenAI 为了展示 Codex 的“Skills（技能）”能力，直接演示了一个精彩的案例：用一句话，徒手搓出一个 3D 赛车游戏！
注意，这可不是简单的贪吃蛇，而是包含物理引擎、道具系统、AI 对手和多张地图的复杂游戏。
Codex 在这个过程中，一口气消耗了 700万 Token。它不仅是写代码，还自己当策划、自己当测试。
除了能写代码，Codex 这次推出的Automations（自动化）功能。
你可以设置定时任务，让 Codex 在后台 24 小时为你打工。
比如：每天早上 9 点，自动扫描 GitHub 的 Issue，自动分类 Bug，自动生成日报，甚至自动把修好的代码部署到云端。
OpenAI 总裁 Greg Brockman 都忍不住在推特上喊话：“自从用了 Codex，再回到终端简直就像穿越回了古代！”
