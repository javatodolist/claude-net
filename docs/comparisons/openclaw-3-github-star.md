从 OpenClaw一出来，我就一直在用，
先说说我的使用场景。
我是做产品的，每天要处理大量文档、邮件、需求整理。以前要么开着 ChatGPT 网页反复粘贴复制，要么花钱买各种套壳 App。
自从用了 OpenClaw，这些事情直接在本地跑，打开就用，它对我最大的价值就一个字：顺。用起来顺。
然后聊聊大家都在喊贵的 token 问题。
很多人配置 OpenClaw 默认就去找 API Key，然后说费用很贵
其实根本没必要这样。
我现在的方案：OpenClaw + Codex（OAuth 授权）
配置 OpenClaw 的时候，模型选 Codex，授权方式不要选 API Key，选 OAuth 授权，直接用你的 OpenAI 账户登录。
这样走的是你 ChatGPT Plus 订阅的额度，每月 20 刀封顶，不会单独再扣 API 费用。
说实话我有点困惑，Codex 这个方式已经这么省钱了，为啥论坛里还是有这么多人在抱怨 token 贵？可能很多人压根不知道有 OAuth 这条路？
比使用Claude真的香太多了，难道大家都没有发现ChatGPT才和它是绝配吗，而且现在ChatGPT的订阅也很很简单了。

最后说说 248000 star 这件事本身。
超越 Linux 的 star 数，听起来很唬人，但 star 这东西本来就没法直接类比——Linux 存在了 35 年，那个年代 GitHub 都还没有。OpenClaw 赶上了 AI 爆发期，赶上了信息传播最快的时代，star 增速快是必然的。
但我觉得更值得关注的不是这个数字，而是：它确实解决了一个真实问题。把 AI 助手从「网页工具」变成了「本地工作流的一部分」，这个体验差距是实质性的。
能跑出这个数字，说明这个痛点戳到了很多人。
接用卡兹克的话，我们这一天见证了历史。它是一个里程碑，从今天开始，开源世界的No.1不再是一个开发者工具，而是一个AI代理框架。这个交接本身就是一个见证，也就是基础设施的时代正式让位于代理的时代，开发者的效率工具让位于每个人的AI替身。
