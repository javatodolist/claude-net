省钱技巧：在 ~/.claude/settings.json 中将默认模型设为 Sonnet，仅在遇到极复杂的架构决策时再手动通过 /model 切换到 Opus。
可以多利用“缓存”和“精简”。
Claude Code 强大的上下文理解能力是基于大量 Token 消耗的，所以控制上下文体积就是直接省钱。
1. 激活 Prompt Caching（提示词缓存）： 这是目前最有效的省钱手段。Claude 支持对重复内容（如系统提示词、大型项目背景、工具定义）进行缓存，缓存命中后的读取成本仅为正常价格的 10%。
连贯对话：尽量在同一个 Session 中解决相关问题，因为对话历史会自动缓存，后续提问会非常便宜。
避免无效更新：不要频繁修改 System Prompt，因为这会使之前的缓存全部失效。
2. 主动进行上下文：
及时清除旧任务：任务完成后务必使用 /clear 或 /new，防止陈旧的代码背景在每一条新消息中都浪费你的钱。
巧用 /compact（压缩）：当对话太长时，使用 /compact 命令。它会总结之前的对话，丢弃不重要的细节，显著降低后续消息的 Token 基数。
3. 调整“深度思考”预算： Claude Code 默认开启了高达 32,000 Token 的“扩展思考”预算。
这些思考 Token 是按输出计费的。对于简单的逻辑，可以在 /config 中降低 MAX_THINKING_TOKENS 的上限，甚至直接关闭。
