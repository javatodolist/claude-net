首先，先解决第一个问题。
一、如何安装Claude code
这里以苹果电脑为例，苹果的会教程会简单很多，Windows的安装教程比较复杂，如果你是Windows用户，可以在评论区留言，我会发一份给你。
1.前置条件
首先看看你的电脑是不是符合这些配置
系统：macOS 10.15 及以上
Node.js ≥ 18（Claude Code 要求）
2.安装 Homebrew
这里我推荐使用Homebrew进行安装，因为只需一条命令就能安装常用工具，足够的小白。
传送门：https://brew.sh/
打开「终端」执行： /bin/bash -c “$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)” 
装完按提示把 brew 加入 PATH，然后验证：
brew –version 
3.安装 Node.js
使用 Homebrew 安装（LTS 即可）
 brew install node 
node -v 
确保版本号 ≥ 18（例如 v18、v20、v22 等），因为 Claude Code 明确要求 Node.js 18+
4.安装 Claude Code
用 Homebrew只需一条命令即可安装成功，因为我之前已经安装过了，所以就没有安装了。
brew install –cask claude-code 
安装好了，验证一下是否安装成功。
claude –version 
看到这里，就安装成功了
