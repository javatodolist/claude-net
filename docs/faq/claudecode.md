Claude Code是什么？
一句话说完：它是一个住在你终端里的编程Agent。
不是那种你问它一个问题、它给你一段代码、你再复制粘贴进IDE的工具。
它是真的能读懂你整个项目的文件结构、理解代码依赖关系、跨文件修改、自己跑测试、发现报错自己改、管git，然后把整件事从头做到尾的Agent。
你描述你想要什么，它去干，干完告诉你结果。
这就是为什么它会被单独列出来，跟那些"高级聊天框"不是一个东西。
国内用Claude Code，有两条路。
先把最现实的问题说清楚。Claude在国内官方不开放，风控严格，账号高强度使用不出三天就可能被封。所以怎么用上它，是第一个要解决的问题。
目前主流的方法有两条：
方法一：订阅Claude官方会员，自己解决网络问题
官方的Pro订阅是每月20美元，Max是100美元或200美元，后者才能无限量跑Claude Code。
支付问题去wildAI（邀请码AIG）解决，它支持国内支付方式，也是目唯一封号会退款的平台。
传送门：https://bewild.ai?code=AIG
网络问题是重点。家庭IP是最安全的，你可以去http://ping0.cc/ip/测一下自己的IP类型，显示"原生/家庭IP"就没问题，显示"IDC机房"就得换。
另外不要频繁切换IP，登录后尽量保持稳定，同一天内跨多个地区是高风险行为。
这条路的优点是功能完整，体验原汁原味。缺点是需要折腾，而且封号风险始终存在。
方法二：使用Claude Code中转站
这是目前国内用Claude Code最稳定的方式。
推荐0011.ai，这是国内运营时间最久、也最稳定的CC中转平台之一。
传送门：https://0011.ai/i/AIG
它的原理是使用Claude Max高级账户池，走官方原生API，通过代理服务器做负载均衡，把请求分散到多个账户上。
效果和直接用官方账户完全一样，但封号风险由平台承担，不需要你操心。
价格上比官网便宜不少，Pro套餐14美元一个月，Ultra版每天有16美元的Claude Code额度，对大多数用户来说完全够用。同时也支持最新的Opus 4.6和GPT Codex。
装好了，怎么开始用？
第一步：安装Node.js
去http://nodejs.org下载最新LTS版本安装，这是Claude Code的运行环境。
Windows用户还需要额外安装Git for Windows，否则依赖安装会出问题。
第二步：安装Claude Code
打开终端，输入：
npm install -g @anthropic-ai/claude-code
装完之后验证一下：
claude --version
能看到版本号就说明装好了。
第三步：配置API Key
如果你用的是0011.ai，订阅套餐之后平台会给你一个API密钥。打开Claude Code的设置，找到模型配置，把Key粘贴进去就行。
如果你用的是官方订阅，会提示你授权Claude Pro会员的账号。
下面这个教程很详细。
第四步：进入你的项目，启动Claude
cd 你的项目文件夹 claude
回车，就进来了。
Claude Code之父Boris Cherny自己公开过他的工作流，有几点我觉得特别值得学。
先规划，再动手。 大多数人上来就让Claude写代码，结果改了一遍又一遍。Boris的习惯是先进Plan Mode，连按两次Shift+Tab就能切换进去。先把计划和Claude对齐，计划确认了再让它开始写，一次到位的概率会高很多。
给Claude验证的方法。 这是Boris认为最重要的一点。你让Claude写完代码，还要给它一个能自己测试结果的方式，比如配合浏览器插件让它自动测UI，或者让它跑测试用例。有了反馈闭环，最终代码质量能提升2到3倍，这不是虚的。
建一个CLAUDE.md文件。 这个文件是给Claude的"团队规范"。你发现它在某个地方反复犯同样的错误，或者有些写法不符合你的要求，就把正确的做法写进这个文件。下次它启动会自动读取，避免重复踩坑。
同时开多个进程。 Claude Code可以同时跑多个任务，不需要等一个做完再开始下一个。Boris自己同时跑5个终端进程，效率直接翻倍。
个人的感觉是你用过之前，很难想象它能做到什么程度。
用过之后，你会很难回去。
