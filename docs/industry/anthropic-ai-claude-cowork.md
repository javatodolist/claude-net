# 如何评价Anthropic 发布通用AI代理 Claude Cowork，目前实际使用怎么样？

同名“AI工具导航站”，跟上时代的脚步

就在昨天，Anthropic 突然发布了一款全新的AI产品——Cowork。
官方给它的定位非常直接：适用于你「其他工作」的 Claude Code。
Claude Code 发布后火得一塌糊涂，Anthropic发现，很多人还经常使用它来干非编程的活儿，比如写小说、做攻略。
如果还不会使用Claude code的，可以看我之前的文章：一个平台，可以同时使用CC和Claude codex
废话不多说，Anthropic 显然是看懂了大家的需求：我们不是想要一个只会写代码的AI，我们想要的是一个真正能自己干活的AI。
于是Cowork诞生了！
不需要敲命令行，不需要懂代码，只要你会打字，就能使用Claude code的同款能力。
更有意思的是，Claude之父Boris Cherny甚至直接指出：Cowork 的代码 100% 都是由 Claude Code 敲出来的。
这简直就是 AI 在生 AI，套娃实锤了！
目前，Cowork 的研究预览版已经上线，Claude Max 订阅用户可以在 macOS 上抢先体验。
那Cowork 到底能干啥？
简单来说：授权 Claude 访问你电脑上选定的文件夹，然后Claude 就可以读取、编辑或在该文件夹中创建文件。
给大家看几个例子就知道是怎么回事了！
AI大V Simon Willison分享到：他有46篇草稿文件，要搞清楚哪些已经发布过。
之前的做法要么是一个一个进行比对或者是自己写脚本自动化，而现在，他直接把这46篇文件扔给Claude的Cowork。
给出指令：帮我查出所有重复或已发布的。
结果Cowork能精准地把那些已发布的文件挑了出来，并附上了一份详细的分析报告。
还有用户使用Cowork帮他们从320份播客文字稿整理出人工智能时代生存的10项重要技能。
以及使用Cowork将有一堆松鼠视频素材（杂七杂八的格式）转成MP4、并加了VHS滤镜、标上时间戳。
Claude自己规划了整个流程，批量全部处理完成。
除了操作文件外，进阶玩法也不少。
Cowork支持接入你已有的连接器（Connectors）。
通过它们，你就能让Claude接入你的云盘、邮箱、项目管理工具，一整套外部数据整合起来，协作就能跨越多个系统。
不过有用户实测Gmail连接器在Cowork无法使用。
同时Anthropic官方坦言了两个风险——
Cowork可能删除你的本地文件，且它可能误解你的意思。（这不是和隔壁的Antigravity一样吗）
另外则是提示词注入风险，黑客可能会利用漏洞，通过Claude在网上看到的内容去改变它的计划，让它反水去翻你的隐私文件。
当然，在兴奋之余，我们也要保持一份冷静。
归根结底，Cowork 目前仅仅是一个“研究预览版”的早期产品。
虽然演示很惊艳，但它在复杂的实际工作流中到底能抗住多大的压力，是否真的能像Claude Code一样火爆尚不可知。
毕竟在 AI 圈，我们见过太多 demo 满分、实测翻车的案例。
但有一点是可以预测的：潘多拉魔盒已经打开。
不出意外的话，国内的大厂们已经在连夜开会了，相信很快我们就会看到国内版的“Cowork”接踵而至。
