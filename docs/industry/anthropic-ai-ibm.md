# 如何看待 Anthropic 用 AI 改写代码致 IBM 大跌？将对软件外包和咨询行业带来哪些影响？

Anthropic发了一篇博客，IBM市值蒸发了310亿美元。
2026年2月23日，一个普通的周一。
Anthropic在官网发了篇博客，说Claude Code现在可以用来做COBOL代码的现代化改造了。
就这一篇文章。
IBM股价当天直接跳水13.15%，创下自2000年10月以来最大的单日跌幅，市值从2408亿美元跌至约2087亿美元，单日蒸发约310亿美元。 这已经是Anthropic今年第三次把某个行业的股价打趴下了。
1月30日发布Claude Cowork的11款企业插件，软件股单日蒸发约3000亿美元，汤森路透跌16%，Salesforce跌44%，Adobe跌42%。
上周五发布Claude Code Security代码安全扫描功能，一堆网络安全公司集体暴跌。
这次轮到IBM。
先说COBOL是什么，以及为什么它这么重要。
COBOL，全称通用面向商业语言，1959年诞生，比我爸妈年纪都大，很多人的爷爷奶奶那辈才入职社会的时候这门语言就已经存在了。
但它至今没死。
美国约95%的ATM交易都依赖COBOL，大量航空系统和政府核心数据库也在跑COBOL。
IBM几十年的核心商业模式就建立在这上面：卖专门跑COBOL的大型主机，然后收昂贵的维护费和咨询费。客户改不掉、离不开，所以IBM才能年复一年稳稳赚这笔钱。
这是一门绝对意义上的"看门生意"。
问题是，懂COBOL的程序员每年都在减少，培训新人的努力也没有实质效果，所以从COBOL迁移出去的风险和成本一直高得离谱，企业根本不敢动。
这就是IBM护城河的本质——不是技术多先进，是迁移成本高到没人愿意动。
然后Anthropic说：AI可以把这个成本打下来。
Anthropic在博客里说，Claude Code可以自动梳理COBOL代码的依赖关系、生成文档、识别风险，把以前需要大量顾问花费数年时间完成的工作，压缩到几个季度内。
有人在X上晒出自己的案例：之前每年花210万美元请IBM团队来维护COBOL系统，用Claude Code只花了9个小时搞定，原来的团队直接解散了。
这个案例不管是不是个例，传播出去的威力是巨大的。
华尔街的逻辑很直白：如果迁移成本不再高不可攀，IBM的护城河就塌了一半。
先卖再说。
但等等，这件事有一个特别有意思的细节。
IBM自己在2023年就推出了一款叫"watsonx Code Assistant for Z"的AI工具，专门用来把COBOL转换成Java。也就是说，用AI处理COBOL这件事，IBM三年前就在做了。
结果，自家做了三年的功能，竞争对手发一篇博客，自己的股价跌了13%。
这说明什么？
市场不是在惩罚IBM的技术落后，是在惩罚IBM的商业模式本身。
IBM做AI改造COBOL，是为了继续维持这门生意；Anthropic做这件事，是为了让这门生意消失。两件事表面上一样，但方向完全相反。
投资者看穿了这一点。
最后说说我自己的判断。
这次IBM暴跌，市场的反应有点过度，但方向没有错。
Anthropic这一年干的事情有一个很清晰的脉络：把AI的能力一刀一刀插进企业最值钱的业务里。法律、金融、销售、安全、遗留系统改造，每插一刀都有一批公司的股价先跌为敬。
这不是Anthropic在攻击这些行业，是市场在重新给这些行业的未来定价。
对做软件咨询和外包的人来说，我觉得该问的问题不是"AI会不会抢我的饭碗"，而是"我现在做的这些事里，哪些是AI擅长的，哪些是AI干不了的"。
擅长的那部分，早点想好退路。干不了的那部分，是你未来的护城河。
越早想清楚这个问题，越主动。
