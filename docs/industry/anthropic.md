# 美国政府「首次封杀」全球头部大模型企业，美联邦机构停用Anthropic产品，会对市场造成何种影响？

北京时间2月28日上午，Anthropic在官网发布了一份正式声明。
这是在特朗普下令封杀Claude将近24小时之后，Anthropic第一次公开开口说话。
翻译成中文是这样的——
大致意思就是：
Anthropic被美国政府列为"供应链国家安全风险"，起因是拒绝移除Claude的两条使用限制：禁止大规模监控美国公民、禁止用于全自主武器。
Anthropic表示这一指定法律上站不住脚，将上法庭挑战。
对普通用户没有任何影响。
如果你还不知道前因后果，我先用最短的篇幅把来龙去脉交代清楚。
事情是怎么发生的
2025年7月，Anthropic跟美国国防部签了一份价值2亿美元的合同，Claude由此成为第一个、也是唯一一个被部署进五角大楼机密网络的前沿AI模型。
合同里，Anthropic附带了两条限制：
第一，禁止将Claude用于对美国公民的大规模国内监控。
第二，禁止用于全自主武器系统，也就是那种人类完全不参与决策、AI自己选目标自己打的杀伤性武器。
合同签的时候，双方对这两条都没有公开表示异议。
但后来，五角大楼开始向所有AI供应商推行一个新的标准条款，叫做"所有合法用途"，意思是只要军方认定某种用途合法，供应商不能设限，不能干预。
OpenAI、谷歌、xAI都接受了。
Anthropic拒绝了。
2月25日，国防部长Hegseth和Anthropic CEO Dario Amodei当面谈判，给出最后通牒：2月27日下午5:01之前，必须移除所有限制条款，否则终止合同。
2月26日深夜，Dario公开声明：不妥协。
2月27日下午4点，距离最后期限还有一个多小时，特朗普抢先在Truth Social发文，痛斥Anthropic高管是"激进的左翼疯子"，下令所有联邦机构立即停止使用Anthropic的技术，并给予六个月过渡期。
下午5:30，国防部长Hegseth宣布将Anthropic列为"供应链国家安全风险"。
这个标签，上一次被用在一家知名公司身上，是2019年的华为。
Anthropic的回应，有几个细节值得认真看
第一个细节：声明发出时，Anthropic还没收到任何正式通知。
他们是看到Hegseth在X上发的帖子才知道这件事的。
整个封杀过程，从宣布到Anthropic回应，全程发生在社交媒体上，没有走任何正式的政府对企业通知程序。
美国政府封杀一家本土AI公司，用的是发推特的方式。
第二个细节：Hegseth的声明，可能超出了他的法定授权范围。
Hegseth原话是：任何与军方有业务往来的承包商、供应商、合作方，即刻被禁止与Anthropic开展任何商业活动。
这个范围如果成立，影响会非常大，因为美国几乎所有大型科技公司都或多或少跟军方有业务关系。
但Anthropic援引了具体法条（10 USC 3252）指出，该条款的法定授权只能限制承包商在国防部合同范围内使用Claude，无法延伸到承包商服务其他客户时的商业行为。
如果这个判断成立，实际影响比看起来小得多：普通用户、持有Anthropic商业合同的企业，完全不受影响；国防部承包商也只是在执行国防部合同时不能用Claude，其他业务照常。
Anthropic已经宣布将在法庭上挑战这个标签的合法性，原话是："我们认为这一指定在法律上站不住脚，并将为任何与政府谈判的美国公司设立危险先例。"
最荒诞的部分在这里
事情到这里已经够戏剧性了。
但真正让人目瞪口呆的，是接下来发生的事。
Anthropic被封杀之后几个小时，Sam Altman公开表态：OpenAI与Anthropic持有完全相同的红线，我们反对大规模监控，反对全自主武器，人类必须保持在决策链上。
然后，OpenAI拿着跟Anthropic一模一样的条款去跟五角大楼谈判。
然后，五角大楼同意了。
Dario因为坚持这两条红线，被骂成左翼疯子，2亿美元合同蒸发，公司被列入国家安全风险名单。
Sam拿着同一套红线，被五角大楼评价为"对安全表现出高度尊重"，顺手接走了Claude留下的市场空缺。
这件事的本质，已经不是红线的问题了。
五角大楼并不是不能接受"不监控、不自动杀人"的条款，他们只是不能接受Anthropic。
对普通用户的实际影响
说完这些宏大叙事，说一个你可能最关心的问题：我还能用Claude吗？
答案是：能。
封杀令的范围是联邦政府机构，以及在执行国防部合同时使用Claude的承包商。
Claude.ai、Claude API对普通用户和商业企业的正常使用，明确不在封禁范围之内。
而且六个月过渡期从2月27日起算，截止2026年8月底，期间Anthropic还被要求继续为国防部提供服务并配合技术迁移。
所以你手里的Claude账号，现在什么都不会变。
Anthropic估值3800亿美元，年收入约140亿美元，今年原计划IPO。
2亿美元的直接合同损失，在财务层面说实话不是致命的。
真正的变量是两个：一是这场法律战打到什么程度，供应链标签最终被法院认定的覆盖范围有多大；二是这个标签会不会让企业客户开始重新评估自己跟Anthropic的关系。
这件事还没有结束，我们敬请期待后续
