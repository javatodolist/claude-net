# Claude 开始查证件了 这次被卡住的 不只是国内用户

## 写在前面
突然掀桌子了。

4 月 16 日，Anthropic 官宣“查户口”：对 Claude 的部分使用场景上线强制“身份验证”（KYC）机制。只要访问特定高级功能，或者触发平台完整性检查，系统就会要求你掏出政府颁发的护照、驾照、国家身份证，同时打开摄像头完成人脸比对。

复印件、截图、扫描件、数字证件、临时证件，统统不行。

更狠的是，这套验证不是一次性的。Anthropic 并没有把触发条件讲清楚，只模糊写了“部分用例、某些功能、平台完整性检查，以及其他安全和合规措施”。这意味着，你今天可能还用得好好的，明天再打开就被要求重新验证；一旦失败，账号就可能直接被禁用。

说白了，这一刀下去，中国大陆这类“不支持地区”的用户，使用 Claude 的路，基本被封死了。

## Anthropic 为什么突然像防贼一样防着用户？
表面看，这是平台开始收紧风控；但把时间往前拨十天，事情就顺过来了。

十天前，Anthropic 公布了新一代网络安全模型 Claude Mythos Preview。在内部红队测试里，Mythos 展现出的能力已经不是“更懂安全”这么简单，而是能够在几乎没有人工干预的情况下，自主扫描代码库，发现跨越主流操作系统和浏览器的零日漏洞。

它挖出的也不是边角料问题。OpenBSD 里埋了 27 年的漏洞、FFmpeg 里藏了 16 年、还躲过数百万次自动化扫描的漏洞，都被它重新翻了出来。

这意味着，过去那种“发现漏洞 -&gt; 编写利用链 -&gt; 厂商打补丁”的几个月时间差，正在被压缩到更短。模型一旦发展到这个级别，平台最担心的就不再只是白嫖、共享号和灰产调用，而是更高风险的武器化问题。

所以现在再看强制 KYC，这件事就没有那么突兀了。

当 AI 的破坏力已经被推到国家安全和关键基础设施这个量级，Anthropic 不可能继续允许挂着代理 IP 的匿名用户随意调用能力。强制 KYC，不只是为了拦白嫖党，更像是在给高风险模型能力加一道更硬的闸门。

![](/assets/images/localized/inews.gtimg.com-e2086d89c969.png)

## 真正让人不舒服的，不只是验证本身，而是谁来接你的证件和人脸
这套身份验证背后，站的是 Persona。

Persona 不是什么小透明公司，但它在隐私和数据安全语境下也绝不轻松。此前它就卷入过数据暴露争议，身份证照片、姓名、邮箱、IP 这类信息一旦泄露，对用户来说几乎没有挽回空间。

更关键的是，这套系统显然不只是“拍张证件照，做一下人脸比对”那么简单。它背后会跑大量验证项，把身份信息、生物特征、环境信息和更广泛的风险检查、合规流程放在一起处理。

问题一下就变得很现实：当一个来自“不支持地区”的用户，挂着 VPN，试图拿自己的证件去过 Claude 的 KYC 时，平台看的已经不只是“证件是不是真的”，而是整套身份链路能不能经得起审查。

这也解释了为什么很多人会对这次更新反感到极点。Anthropic 一直把自己放在“更强调安全、更强调责任边界”的位置上，但当这种安全策略开始直接索取护照、身份证和人脸数据时，用户最自然的反问就是：为了安全，难道就必须以自己的隐私为代价？

## Anthropic 其实未必在乎流失这批人，因为它现在最重要的是 B 端
如果还是用消费级产品的逻辑去看这件事，很容易误判。

Anthropic 现在最核心的增长引擎，已经不是普通用户订阅，而是企业级重型部署。过去一年，它的收入和估值增速都快得夸张。更重要的是，推动它往前冲的不是大众用户有多喜欢 Claude，而是越来越多金融、医疗、律所和顶级科技公司把它当成企业基础设施采购。

![](/assets/images/localized/inews.gtimg.com-50584370a4b9.png)

站在这个商业结构上再看，Anthropic 的优先级其实非常清楚。

它要稳住的是高合规要求的大客户，要维持自己在企业采购体系和监管语境里的可信形象，要避免在“供应链风险”“模型滥用”“敏感能力外流”这些问题上被打低评级。

在这种背景下，C 端体验、全球普通用户的不满、灰色地区的访问便利性，都不会排在最前面。对 Anthropic 来说，真正贵的不是流失一批骂声很大的用户，而是因为风控不够硬，丢掉后面更大的企业订单、政府信任和资本市场预期。

换句话说，这次强制 KYC 不是一时兴起，也不只是法务突然收紧，而是它当前商业结构下非常自然的一步。能力越危险，客户越大，规则就会越硬。

## 对国内影响最大的，可能不是普通用户，而是中转和套壳生态
把视角拉回国内，影响会更直接。

Anthropic 的强制 KYC 政策，对于极度依赖海外大模型的“套壳”生态，是一次不小的打击。首当其冲的，就是 API 代理中转商、共享号、订阅分销和账号合租这类链路。

过去这套模式能跑起来，很大程度上依赖的是平台验证还不够强，账号还能批量注册、接口还能被层层转手、订阅还能被拆开倒卖。

但强制 KYC 打的恰恰就是这个环节。

一旦平台在关键节点弹出实时活体验证，要求本人证件、本人摄像头、本人面部比对，很多原本靠代注册、代充值、共享号和代理链路维持的模式，都会一下子变得脆弱。网络可以代理，真人身份很难长期代理。

从这个角度看，这次更新带来的震动，远不只是“国内用户更难用 Claude 了”。它同时说明，顶级模型厂商已经开始把访问控制、安全合规和商业筛选放进同一个系统里统一处理。

对普通开发者来说，现实问题也很直接：官方订阅本来就不算轻松，既要处理支付，也要处理网络和账号环境。Claude Pro 一般是 20 美元/月，Max 会更高，档位越高，对应的调用额度和使用上限也越高。

## 常见问题

### 1. Anthropic 这次强制身份验证，最关键的变化是什么？
不是多填一份资料这么简单，而是 Claude 在部分高敏感场景里开始要求真实身份和活体人脸验证，而且验证可能是触发式的，不一定只出现一次。

### 2. 为什么偏偏是现在开始收紧？
因为模型能力和平台风险都在往上走。尤其是 Claude Mythos Preview 这类高风险安全能力出现之后，Anthropic 更不可能继续放任匿名访问和灰色链路。

### 3. Persona 只是普通的 KYC 厂商吗？
不是。它承接的不只是证件核验，还涉及更深层的风险检查和合规流程，所以外界对隐私和数据安全的担忧会更强。

### 4. 这次最受冲击的是谁？
除了“不支持地区”用户，依赖账号共享、API 中转、订阅分销和套壳接入的那批生态也会明显受冲击，因为实时活体验证很难被批量代理。

### 5. Anthropic 会因为这波动作流失很多用户吗？
会有争议，也会流失一部分用户，但从它当前的企业化路线看，这未必是它最在意的损失。对它来说，更重要的是守住安全、合规和大客户信任。
