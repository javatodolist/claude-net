我身边不少做科研和开发的朋友，现在照样天天用 Claude Code 写代码、跑实验、做论文，根本没有什么"用不了"的问题。

不过我更加推荐大家去使用官网的服务，毕竟订阅了Claude会员后，还可以使用cc、cowork和桌面版Claude code，很香。
扯远了，回到问题：那我们到底会不会落后？
我的答案是：会，但原因跟 Claude Code 封不封没什么关系。
真正决定一个国家在 AI 领域能走多远的，从来不是哪个工具能不能访问，而是几个更底层的东西：
算力。 英伟达的出口管制才是真正的卡脖子。高级芯片进不来，你有再好的模型，训练能力也受限。这不是多开一个代理能解决的事。字节很火的那个模型据说都是使用的海外的芯片，在海外训练成的。
人才密度。 顶级 AI 研究员的聚集效应，比任何工具都重要。
OpenAI、Anthropic、DeepMind 能持续产出，不是因为他们用了什么神秘工具，而是因为那里汇聚了一批真正顶尖的人。
而且他们彼此之间的思维碰撞和信息流动是极其自由的。
除此之外， 做前沿研究，需要快速获取、消化、讨论最新进展。
这个环境，比工具本身重要一个数量级。
还有就是钱，大家都绕不过，相信大家没有忘记ChatGPT计划投资多少钱到AI上，非常多。
我认识一个在做生物信息学研究的朋友，课题组在二线城市的高校。
他们一直都有自己的方法使用Claude code，主要是觉得国内的消息密度太低了，氛围也没有海外那么浓郁。
所以，真正会落后的，永远不是模型，而是人才流失、芯片断供、信息流通不畅、科研环境的压抑感。
