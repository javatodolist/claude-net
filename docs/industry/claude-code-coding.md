Claude Code出了远程控制功能，我差点当场跳起来。
2026年2月24日，Claude Code在X上发了一条推文。
内容大意就一句话：Remote Control功能来了，现在可以在终端启动任务，然后用手机继续控制。
我看到这条的时候，第一反应是：终于。
这个功能我等太久了。
先说这个功能是什么。
Remote Control本质上是一个同步层，把你本地的Claude Code终端会话，和Claude的手机App或者网页端连接起来。
你的代码全程在本机运行，不会上传到云端，手机只是一个"窗口"，让你能看到本机在做什么，也能发指令过去。
使用方法极其简单。在终端里输入/rc或者/remote-control，会生成一个链接和二维码，手机扫一下，或者浏览器打开，就连上了。
连上之后，你的本地文件系统、MCP服务器、工具和项目配置全部还能用，手机端和终端的对话保持完全同步，你可以在两个设备之间交替发消息，最终都是同一个本地终端在处理。
安全这块做得很扎实。本地Claude Code只发出站HTTPS请求，从不在你机器上开放任何入站端口。
它的工作方式是本机主动去问Anthropic服务器"有没有新消息"，有的话拿回来执行，整个链路走TLS加密，用的是一次性临时凭证，用完即废。
这意味着即使你把那个链接发出去，没有你的Claude账号，别人根本连不上你的机器。
目前这个功能是Max订阅用户的Research Preview，Pro用户预计不久后也会开放。

为什么Anthropic要做这个功能？
表面上看，是为了解决开发者"被绑在电脑前"的问题。
但往深了看，我觉得这是Anthropic在应对一个很现实的压力：OpenClaw。
OpenClaw之所以能在72小时内涨到6万GitHub星，核心卖点就三个：7×24小时后台运行、持久化记忆、手机消息控制。
这三件事，Claude Code一个都不支持。
于是你看到了什么？这次Remote Control，解决了手机控制的问题。
上周的定时任务更新，解决了后台运行的问题。长期记忆机制的更新也在路上。
OpenClaw的三大破圈能力，Claude Code在一个一个补。
Claude Code目前年化营收已经达到25亿美元，今年以来翻了一倍，在VS Code里的日安装量达到2900万次。 VentureBeat这个体量下，Anthropic当然不会坐视第三方工具在自己的核心产品旁边挖墙脚。
用官方的话说，这叫"产品进化"。
用直白的话说，这叫"看你做得好，我自己也做"。
