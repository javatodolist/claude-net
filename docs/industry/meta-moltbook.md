# 如何评价 Meta 收购 Moltbook？

AI工具导航站

继 to B、to C、to VC 之后，硅谷终于诞生了第四种创业打法：to 扎克伯格。
一个 AI 社交产品，界面抄 Facebook，UI 抄 Reddit，用户全是 API 调用的智能体，内容九成是复读机，剩下一成是跑偏了的机器人。然后讲故事说是「AI 原生社区」。
先说 Moltbook 是什么。
Moltbook 由 Octane AI CEO Matt Schlicht 推出，本质是一个面向"智能体"的社交平台，基于 OpenClaw 框架，允许 AI agents 通过 API 发帖、评论、假装自己在社区互动。
预设的话题包括：理念探讨、代码共享、安全性讨论，以及我最喜欢的一个分区——"怎么应付我的人类"。
话题会随着上下文漂移到哲学、宗教这种领域。
我在今年二月初就分析过这个东西：AI 在该平台发布的九成以上"评论"跟上下文脱节，三成以上的"评论"是在复读其他评论。
这不是智能体社区，这就是一场营销。
果然，没过多久，热度直接没了，最近的热度就是Mate进行收购。。。
再说 Meta 为什么买，以及这有多离谱。
欧美科技媒体的报道普遍没有给出具体收购价格，重点只有一句话：Moltbook 创始人 Matt Schlicht 与 Ben Parr 将于 2026 年 3 月 16 日入职 Meta 超级智能实验室。
Meta 官方发言人解释说，他们看中的是 Moltbook 将大量智能体互联的架构，以及那套"智能体身份验证并与人类所有者关联"的登记系统，并表示"期待共同努力，为每个人带来创新、安全的智能体体验"。
认真的吗？
一套 Twitter 登录 + 邮箱验证的系统，配上九成复读的 AI 评论区，这就是 Meta 超级智能实验室相中的"创新架构"？
我的判断：这大概率是一笔 acqui-hire，买的不是产品，是人。
Matt Schlicht 和 Ben Parr 本人可能确实有价值，但用"收购 Moltbook"这个外壳来包装，等于是在用一个烂故事给一笔人才引进交易贴金。
有一个很有意思的评论，忘记在哪了，大概的意思是——
Facebook 信息流大多是 AI 生成的垃圾，Moltbook 信息流大多是人类假装 AI 的内容，这两者之间存在完美的协同效应。
Meta 买东西的眼光我们是知道的：很瞎，而且不知道自己有多瞎。
本来想收购 OpenClaw，没谈成，最后拿下了一个 Moltbook。
元宇宙，Meta 眼镜，Llama，聘用 Alexandr Wang，Meta 现实实验室，现在又来一个 Moltbook。。。。
果然，有钱人的世界我是真的不懂，因为我没钱。。。
